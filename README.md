# Quad Cortex Android Editor

An independent, touchscreen editor for the Neural DSP Quad Cortex, designed to make tone editing, live performance, and guitar practice more intuitive and accessible.

## Features

- Full touchscreen editing of amps, effects, routing, and presets
- Bidirectional USB communication with compatible Android devices
- Bluetooth MIDI controller integration
- Custom amp and pedal interfaces
- Integrated YouTube practice mode with playback, looping, and speed controls
- Live performance controls and scene switching
- AI-assisted tone generation and refinement
